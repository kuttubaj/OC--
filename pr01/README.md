# ПР-1, Вариант B

## 1. Попытка удалить файл
Вывод в терминале:
iskak@AserNitro:~$ rm /srv/shared/testfile.txt
rm: remove write-protected regular empty file '/srv/shared/testfile.txt'? y
rm: cannot remove '/srv/shared/testfile.txt': Permission denied

Почему так вышло:
Файл удалить не получилось, потому что в Linux право на удаление зависит от папки, а не от самого файла. Папка /srv/shared принадлежит root и группе developers. Мой пользователь (iskak) в эту группу не входит, поэтому у меня есть права только на чтение папки, а прав на запись (и удаление) в нее нет.

## 2. Чем su отличается от sudo
* `su` — полностью переключает на другого пользователя. При этом нужно вводить пароль того, к кому заходишь.
* `sudo` — дает права админа только на одну конкретную команду. Тут нужно вводить свой собственный пароль.

## 3. Почему root заблокирован
Ради безопасности. Во-первых, никто не сможет подобрать пароль от главного админа, потому что пароля просто нет. Во-вторых, чтобы случайно не сломать систему — для любых системных изменений приходится осознанно писать sudo.
